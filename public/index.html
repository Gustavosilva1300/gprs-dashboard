Como configurar o ESP32 GPRS

Envie um HTTP GET para o endpoint abaixo com os parâmetros dos sensores:

http://<IP-DO-PC>:3000/data?temp=25.3&umid=60&baro=1013&alt=500&volt=220&p1=10.5&p2=10.3&motor=75&lat=-23.55&lon=-46.63&sinal=18&chip=1&coletando=1

Também aceita HTTP POST (JSON ou form-urlencoded) com os mesmos campos.
